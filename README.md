# Camunda 8 – Workflow Automation Practical Assignments

## Overview

This repository contains three practical workflow automation assignments implemented using Camunda 8.

The assignments demonstrate business process automation using BPMN, DMN decision tables, Java Spring Boot external job workers, REST API integration, process variables, human tasks, monitoring and incident recovery.

## Technology Stack

- Camunda 8 Modeler
- BPMN 2.0
- DMN
- Java
- Spring Boot
- Maven
- REST APIs
- Python (mock APIs)
- Camunda Tasklist
- Camunda Operate

## Labs

### Lab 1 – End-to-End Loan Approval Automation

Develops a loan approval workflow that validates applicant details, retrieves simulated credit information, applies DMN decision rules and routes applications to approval, rejection or manual review.

**Status:** In progress

### Lab 2 – E-Commerce Order Processing and Fulfilment

Develops an order-processing workflow that validates orders, checks stock availability, determines delivery priority, processes simulated payments and routes orders to fulfilment or manual review.

**Status:** Not started

### Lab 3 – Hospital Appointment and Patient Triage Management

Develops a hospital appointment workflow that validates synthetic patient details, classifies requests using DMN, checks appointment availability and routes cases for staff assessment or booking.

**Status:** Not started

## General Notes

- All test data is synthetic.
- Mock APIs are used for service integration.
- No real payment credentials or patient information are included.
- Screenshots are captured from the actual implementation.
- Test results are documented after workflow execution.
